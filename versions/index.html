One version for the site and the extension, in admin/build/version.txt. Every push to dev is a release: CI validates, runs the tests, tags vX.Y.Z on the commit whose subject carries it (site vX.Y.Z: ...), then publishes the site.

meetscribe.chrome-extension

A Chrome extension that transcribes the Google Meet call you are in, on your own OpenRouter key: no bot, no Google recording, no server of ours. First MVP, loaded unpacked. Content CC BY 4.0; code Apache 2.0.
